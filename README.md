# 🎵 Melody Rush

**Melody Rush** is a casual 3D rhythm-inspired game developed in Unity using C#. The game challenges players to navigate through a musical environment while dodging obstacles and maintaining momentum.  

---

## 🕹️ Gameplay

- Navigate a 3D path filled with obstacles
- Background music enhances the game experience
- Simple controls and intuitive interface
- Increasing difficulty over time

---

## 🔧 Technologies Used

- **Unity (3D)** – Game development engine
- **C#** – Scripting and game logic
- **Unity UI System** – Menus, score display, and HUD
- **Unity Audio System** – Background music and SFX
- **Prefab System** – Reusable game objects (obstacles, UI)
- **Collision Detection** – Physics-based interaction
